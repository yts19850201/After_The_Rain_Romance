# 첫 작품 제작 계획

21단계에서 기획한 작은 연애 게임을 22~30단계로 완성합니다. 각 단계의 완료 기준을 확인하고 다음 기능을 붙입니다. 기획에 없는 기능은 별도 목록에 적어두고 첫 엔딩까지 동작한 뒤 검토합니다.

## 22단계 · 첫 장면을 플레이하기

Godot 4 프로젝트를 이 폴더에 생성합니다. 임시 배경·인물 자리·이름·대화창을 배치하고 S01 일부 대사와 C01을 연결합니다. 최종 그림을 기다리지 않고 도형과 임시 색으로 시작합니다.

완료 기준: 처음부터 C01까지 읽을 수 있고, 선택 버튼을 누르면 해당 반응을 한 번 보여준 뒤 이어집니다. 빠른 대사 표시와 선택 확정이 한 번의 입력으로 같이 실행되지 않아야 합니다.

## 23단계 · 두 엔딩까지 이어 붙이기

S01~S03, C01~C03, E01·E02를 임시 대본으로 연결합니다. 호감도는 새 게임에서 0으로 시작하고 선택마다 한 번만 반영합니다.

완료 기준: 8개 선택 조합을 확인해 네 조합은 E01, 나머지 네 조합은 E02로 끝납니다. 재시작해도 이전 점수가 누적되지 않습니다.

## 24단계 · 이벤트와 엔딩 기록

표정·배경 전환과 짧은 화면 전환을 추가합니다. 본 엔딩을 기록하고 감상 화면에서 확인할 수 있게 합니다. CG가 준비되지 않았다면 엔딩 제목과 기본 배경으로 기록 화면을 완성합니다.

완료 기준: 아직 보지 않은 엔딩과 확인한 엔딩이 구분됩니다. 엔딩을 다시 읽어도 게임 진행 상태가 오염되지 않습니다.

## 25단계 · 저장·불러오기

현재 장면·대사 위치·호감도·선택 완료 상태·표정·배경을 저장합니다. 수동 저장은 3슬롯, 설정과 엔딩 기록은 진행 저장과 분리합니다. 별도 저장 슬롯이 필요 없는 새 게임도 지원합니다.

완료 기준: 게임을 껐다 켜도 같은 위치에서 이어지며, 이미 고른 선택의 점수가 다시 더해지지 않습니다. 저장 파일이 없거나 형식이 맞지 않을 때 안내합니다.

## 26단계 · 그림·음악·최종 대본

대본을 확정하고 배경 2종과 인물 표정 4종, 음악·효과음을 적용합니다. 자산 목록에 출처와 이용 조건을 기록합니다. 선택적 엔딩 CG는 기본 자산 적용 후 판단합니다.

완료 기준: 임시 표시를 정리하고 글자 길이·이름·표정·음량을 확인합니다. 사용할 자산의 이용 조건이 기록되어 있습니다.

## 27단계 · 전체 플레이 점검

두 엔딩, 선택 반응, 저장·불러오기, 설정, 입력 중복을 확인합니다. 실제 읽기 시간을 재고 다른 사람에게도 처음부터 읽어보도록 요청합니다.

완료 기준: 분기·대사·저장 오류를 수정하고, 10~20분 목표에 비해 너무 길거나 짧은 부분을 조정합니다.

## 28단계 · 배포·판매 준비

완성한 실제 콘텐츠를 기준으로 배포 플랫폼을 검토합니다. 이 단계에서 해당 플랫폼의 최신 성인 콘텐츠 정책·등록 조건·가격과 수수료를 확인하고 소개글과 화면 자료를 만듭니다. 현재 기획서에서 특정 플랫폼의 판매 가능 여부나 수익을 확정하지 않습니다.

완료 기준: 배포할 콘텐츠 범위와 플랫폼, 가격 또는 무료 공개 여부, 제출 자료를 정합니다.

## 29단계 · 출시용 빌드와 배포

Windows 실행 파일·게임 데이터·안내·라이선스를 패키징하고 프로젝트 밖의 폴더에서 검사합니다. 실제 업로드나 공개는 사용자의 요청에 따라 진행합니다.

완료 기준: 설치·실행·저장과 두 엔딩이 배포본에서도 동작합니다. 배포 페이지의 설명이 실제 게임과 일치합니다.

## 30단계 · 출시 후 점검

사용자가 받은 피드백과 확인 가능한 결과를 보고 오류 수정과 개선 범위를 정합니다. 새로운 캐릭터나 대형 시스템은 다음 작품 후보로 관리합니다.

완료 기준: 수정 내역을 정리하고 첫 작품에서 유지할 점과 다음 작품에서 바꿀 점을 기록합니다.

## 작업 순서의 기준

첫 장면 동작 → 두 엔딩까지 완주 → 저장과 기록 → 최종 자산 → 전체 점검 → 배포 순서입니다. 그림을 모두 만든 뒤 코드를 시작하지 않습니다. 매 단계가 끝나면 실제로 확인한 항목을 README에 갱신하고 로컬 커밋합니다. 푸시는 별도 요청이 있을 때 진행합니다.
