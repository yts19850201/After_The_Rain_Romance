# 관계 중심 고도화 · 31~35단계

기존 작품의 대화·선택·저장을 바탕으로 서윤과의 관계를 깊게 만듭니다. 사용자의 34단계까지 진행 요청에 따라 32~34단계를 함께 구현·검사했습니다. 사용자 직접 플레이 확인은 대기 중입니다.

| 단계 | 내용 | 현재 상태 |
|---|---|---|
| 31 | 호감도 0~3과 관계 단계, 선택 후 증가·유지 안내 | 구현·자동 검사 완료, 직접 확인 대기 |
| 32 | 월~금 5일, 하루 두 행동, 각 행동 하루 한 번 | 구현·자동 검사 완료, 직접 확인 대기 |
| 33 | 관계·행동 조건으로 열리는 이야기 4편 | 구현·자동 검사 완료, 직접 확인 대기 |
| 34 | 30세 민재의 소개와 세 사람의 책 모임 준비 | 구현·자동 검사 완료, 직접 확인 대기 |
| 35 | 엔딩 확장, 저장 호환성 점검, 새 Windows 배포본 | 예정 |

기존 세 방문은 **첫 만남 읽기 · 기존 이야기**에 보존했습니다. 시작 화면과 본편 완료 화면에서 **새로운 한 주**로 들어갈 수 있습니다. 새 일상은 세 번의 만남 뒤 다시 방문하는 주간이며, 주간 호감도 0~10은 독립적으로 시작합니다. 본편의 0~3 점수와 두 엔딩 조건은 유지합니다. 수요일은 휴무 중 초대받은 오전 모임 준비입니다.

일상 저장은 schema 2이며 기존 schema 1도 읽어 알맞은 진행 화면으로 복구합니다. 이전 버전 프로그램은 schema 2를 읽지 못하므로 새 일상은 현재 소스로 이어갑니다. 진행 슬롯은 기존과 같은 3개이며 선택한 슬롯을 수동 저장할 때만 덮어씁니다. 행동 기록에서 점수를 계산하고 대화 중 복구해도 보상을 중복 지급하지 않습니다.

공개한 v0.1.0은 기존 첫 배포본입니다. 현재 소스는 `0.2.0-dev34`이며 실행 도우미 또는 Godot F5로 확인합니다. 새 시작 장면은 `scenes/cafe_life_261022.tscn`입니다. 기존 Windows ZIP은 유지하고 새 패키징은 35단계에 진행합니다. 푸시와 새 릴리스 게시는 사용자의 명시적 요청이 있을 때 진행합니다.
