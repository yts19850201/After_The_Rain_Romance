# 관계 중심 고도화 · 31~35단계

기존 작품의 대화·선택·저장을 바탕으로 서윤과의 관계를 먼저 깊게 만듭니다. 각 단계를 구현·검사한 뒤 사용자가 직접 확인하고 다음 단계로 넘어갑니다. 현재는 31단계만 구현했습니다.

| 단계 | 내용 | 현재 상태 |
|---|---|---|
| 31 | 호감도 0~3과 관계 단계, 선택 후 증가·유지 안내 | 구현·자동 검사 완료, 직접 확인 대기 |
| 32 | 날짜와 하루 행동, 행동 횟수 제한 | 예정 |
| 33 | 관계와 행동 조건에 따라 열리는 추가 에피소드 | 예정 |
| 34 | 서브 캐릭터 1명과 연결되는 작은 이야기 | 예정 |
| 35 | 엔딩 확장, 저장 호환성 점검, 새 Windows 배포본 | 예정 |

32단계부터 행동·조건을 늘릴 때는 기존의 고정 세 방문 이야기와 새 날짜 진행을 어떻게 연결할지 먼저 정합니다. 새 캐릭터나 많은 날짜를 한꺼번에 추가하지 않습니다. 현재의 0~3 수치와 엔딩 조건은 31단계에서 바꾸지 않습니다.

공개한 v0.1.0은 기존 첫 배포본입니다. 현재 소스는 `0.2.0-dev31`이며 기존 실행 도우미 또는 Godot F5로 확인합니다. 푸시와 새 릴리스 게시는 사용자의 명시적 요청이 있을 때 진행합니다.
