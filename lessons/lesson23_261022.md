# 23단계 · 두 엔딩까지 이어 붙이기

목표는 짧아도 처음부터 끝까지 플레이되는 이야기를 만드는 것입니다. `run_game_261022.cmd`로 실행해 세 번의 만남을 읽어보세요.

공통 흐름은 S01 → C01 → S02 → C02 → S03 → C03 → 엔딩입니다. 각 선택의 A는 호감도 1, B는 0을 더합니다. 합계가 2 이상이면 E01, 그보다 낮으면 E02입니다. 숫자는 게임 화면에 표시하지 않습니다. 두 엔딩 모두 다음 만남이 있는 이야기입니다.

대사와 표정은 `data/story_dialogue_261022.json`에서 읽습니다. 한 줄은 `[말하는 사람, 표정, 대사]` 순서입니다. 선택 문구와 점수는 `data/story_outline_261022.json`의 `choices`에서 관리합니다. ID는 두 파일을 이어주는 이름이므로 유지하세요.

## 직접 확인할 것

- [ ] A→A→A와 B→B→B를 골라 두 엔딩을 읽는다.
- [ ] 선택 후 첫 반응을 건너뛰지 않는지 확인한다.
- [ ] 처음부터 다시 시작하면 이전 점수가 초기화되는지 확인한다.
- [ ] 대사 한 줄을 바꾸고 F5로 실행해 비교한다.

호감도만 계산해 엔딩을 고르는 검사와 별개로, 자동 검사에서는 여덟 조합을 실제 대화 흐름으로 끝까지 진행했습니다. 네 조합씩 두 엔딩으로 나뉩니다.
