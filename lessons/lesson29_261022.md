# 29단계 · Windows 배포본 만들기

`builds/AfterTheRain_Windows_v0.1.0_261022.zip`이 전달용 파일입니다. 압축을 모두 풀고 `AfterTheRain_261022.exe`를 실행합니다. exe와 같은 이름의 pck를 함께 보관해야 하며 Godot 설치는 필요하지 않습니다. 실행 안내·버전 기록·엔진과 폰트의 라이선스를 함께 넣었습니다.

배포본을 프로젝트 밖으로 복사해 8개 분기와 저장·감상 기능을 검사했습니다. 게임을 완전히 종료한 뒤 별도 프로세스로 불러오기까지 확인합니다. ZIP을 다른 임시 폴더에 풀어 실제 전달되는 파일의 해시와 실행도 검사합니다. 사용자 저장과 테스트 저장은 분리합니다.

다시 빌드할 때는 Godot 4.7.2 Standard와 같은 버전의 Windows x86_64 release template을 준비합니다. PowerShell 7에서 `tools/build_windows_261022.ps1`을 실행하고 `tools/verify_windows_261022.ps1 -CaptureScreenshots`로 ZIP을 검사합니다. 환경 변수 `GODOT_ROMANCE_EXE`와 `GODOT_ROMANCE_RELEASE_TEMPLATE`로 도구 위치를 지정할 수 있습니다. 도구와 임시 빌드는 Git에 넣지 않습니다.

## 직접 확인할 것

- [ ] GitHub Releases에서 ZIP을 받아 압축 해제한다.
- [ ] Godot를 켜지 않고 exe로 시작한다.
- [ ] 저장 후 종료하고 다시 불러온다.
- [ ] 다른 PC에서도 실행되는지 확인한다.

현재는 개발 PC에서만 확인했습니다. 다른 PC의 호환성과 사람의 실제 읽기 시간은 첫 배포 뒤 수집할 항목입니다.
