# 30단계 · 첫 배포 기록과 다음 수정

첫 버전은 v0.1.0 무료 시험 배포입니다. 자동 검사·배포본 검사와 현재의 한계를 `distribution/qa_report_261022.md`에 남깁니다. 피드백 기록표와 GitHub 이슈 양식을 준비했으며, 실제 피드백이 들어오면 v0.1.1 수정 범위를 정합니다.

아직 사람의 실제 플레이·외부 피드백·다운로드 실적·매출 자료는 없습니다. 첫 배포를 했다는 이유로 출시 성과나 학습 완료를 만들어 적지 않습니다. **30단계의 첫 점검 기록과 접수 준비를 마쳤고, 실제 피드백을 반영하는 후속 작업은 수집 후 진행합니다.**

## 유지할 것

작은 범위로 엔딩까지 완주하는 구조, 대본과 진행 규칙의 분리, 입력 중복 방지, 저장 검증과 별도 엔딩 기록, 자산 출처, 실제 배포 ZIP 검사를 유지합니다.

## 다음 버전에서 확인할 것

1. 실행·저장 오류와 진행 불가 문제를 먼저 수정합니다.
2. 읽기 시간·대화 자연스러움·음량 피드백을 보고 대본과 설정을 조정합니다.
3. 새 캐릭터·3D·대규모 성인 콘텐츠는 이번 수정에 섞지 않고 다음 작품의 기획으로 다룹니다.

## 피드백 남기기

버전, 플레이한 엔딩, 읽기 시간, 문제가 보인 대사나 동작, 다시 발생시키는 순서, 기대한 결과를 적습니다. 공개 이슈에 실명·연락처·개인 파일을 넣을 필요는 없습니다. 원격 자동 점검이나 알림은 별도 요청 없이 예약하지 않습니다.
