# 34단계 · 서브 캐릭터 민재

민재는 **30세 동네 서점 직원이자 책 모임 참가자**입니다. 주인공과 서윤의 관계를 중심에 두고, 함께 모임을 준비할 작은 계기를 만드는 조연으로 추가했습니다. 민재 전용 호감도나 연애 분기는 이번에 만들지 않았습니다.

## 직접 해보기

1. 새로운 한 주에서 월요일을 마치면 화요일 **화요일의 새 얼굴**이 자동으로 시작됩니다. 이 소개에는 행동 횟수가 들지 않습니다.
2. 이름이 민재로 바뀔 때 새 인물 그림이 나오는지 확인하세요. 서윤의 말에는 서윤 그림으로 돌아옵니다.
3. 3일차 이후 호감도 5 이상, 책 읽기 2회, 정리 돕기 1회와 소개 완료 조건을 채우세요.
4. **추가 이야기 → 세 사람이 고른 첫 질문**을 읽고 한 주 기록에 완료가 남는지 확인합니다.
5. 민재 대화 중 저장하고 불러와 같은 인물·문장·남은 행동으로 이어지는지 확인하세요.

행동 대화, 서윤 추가 이야기, 민재 소개와 모임 대화를 합쳐 새 대사는 59개 단위입니다. 실제 플레이 시간과 외부 피드백은 아직 측정·수집하지 않았습니다.

## 그림과 데이터

민재 그림은 OpenAI 내장 imagegen으로 이 프로젝트의 서윤 그림을 스타일 참조해 만들었습니다. 1024×1536 투명 PNG 한 장을 적용했습니다. [그림](../assets/art/minjae_neutral_261022.png), [실제 생성 프롬프트](../assets/art/GENERATION_PROMPTS_261022.md), [출처·이용 조건](../assets/ASSET_SOURCES_261022.md)에 보관했습니다. 별도 이미지 ZIP은 만들지 않았습니다.

인물 정보와 대사는 `data/cafe_life_261022.json`, 화자별 그림 전환은 `scripts/cafe_life_261022.gd`에 있습니다. 자산 검사에서는 파일 해시와 투명 가장자리를 확인합니다.

## 32~34단계 확인 범위

- 5일 진행, 하루 두 번 제한, 같은 행동 중복 차단, 쉬는 진행.
- 네 이야기의 잠금 조건·완료 기록과 민재 소개·화자 전환.
- 행동·소개·추가 이야기 중간과 마무리 화면 저장, 새 프로세스 복구, 점수 중복 방지.
- 잘못된 날짜·행동·점수·조건을 담은 저장 거부, 기존 schema 1 불러오기.
- 기존 이야기 8개 분기와 두 엔딩, 새 화면에서 기존 엔딩 감상 후 복귀 및 한 주 시작 연결.
- 1280×720과 960×540 화면, 새 대사 59개 단위의 잘림 여부.

`tests/cafe_life_261022.gd`, `tests/novel_flow_261022.gd`, `tests/assets_261022.gd`가 통과했습니다. 검사는 `.godot`의 별도 경로를 사용해 실제 저장을 건드리지 않았습니다. 사용자 직접 플레이 확인은 대기 중입니다.
