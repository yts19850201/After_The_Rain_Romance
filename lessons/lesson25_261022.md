# 25단계 · 저장하고 이어 읽기

목표는 종료 후에도 같은 지점에서 이어 읽고, 이미 반영한 선택을 다시 더하지 않는 것입니다.

대화 중 위쪽 **저장**에서 슬롯 1~3 중 하나를 고릅니다. 덮어쓰기 버튼은 해당 슬롯을 즉시 바꿉니다. **불러오기**에서는 저장한 장면과 시간을 보고 이어갈 수 있습니다. 시작 화면에서도 불러올 수 있습니다.

저장에는 장면, 공통 대화·선택·선택 반응·엔딩 중 현재 구간, 대사 번호, 선택 기록과 호감도, 표시한 글자 수, 표정과 배경을 넣습니다. 불러오기 전에 값과 순서를 검사하고 호감도도 선택 기록에서 다시 계산합니다. 잘못된 데이터는 실행 상태에 반영하지 않습니다.

설정은 `settings_261022.json`, 엔딩 기록은 `profile_261022.json`으로 분리합니다. 엔딩 감상에서는 슬롯 저장을 막습니다. 새 이야기는 진행을 초기화하며 슬롯과 감상 기록을 지우지 않습니다.

## 직접 확인할 것

- [ ] 글자가 나오는 중에 저장하고 불러와 같은 글자 위치인지 확인한다.
- [ ] 선택 화면에서 저장한 뒤 다른 답변을 골라본다.
- [ ] 선택 직후 저장하고 게임을 완전히 종료한 뒤 불러온다.
- [ ] 이어 읽어도 선택 점수가 중복되지 않고 기대한 엔딩으로 가는지 본다.
- [ ] 음악 음량과 글자 속도를 바꾸고 다시 실행해 유지되는지 확인한다.

자동 검사는 별도 임시 저장 폴더를 사용하며 실제 플레이의 저장 파일을 덮어쓰지 않습니다. 파일 없음·손상·버전 불일치·잘못된 장면과 선택 조합도 검사합니다.
