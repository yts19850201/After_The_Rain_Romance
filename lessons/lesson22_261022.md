# 22단계 · 첫 대화창과 선택지

첫 장면 S01을 실제로 읽을 수 있게 만들었습니다. 첫 방문의 대화를 지나 C01의 두 답변 중 하나를 고르면 다른 반응을 보여주고, 공통 마무리를 읽은 뒤 첫 만남 완료 화면으로 이동합니다.

## 실행과 조작

1. `open_editor_261022.cmd`를 더블클릭해 새 연애 게임 프로젝트를 엽니다. 이전 슈팅 편집기가 열려 있다면 창의 프로젝트 이름이 **After the Rain - Romance**인지 확인하세요.
2. `scenes/scene01_261022.tscn`을 연 상태에서 F6으로 실행합니다. F5는 현재 26단계 전체 게임을 실행합니다.
3. 첫 만남 시작을 누르거나 Enter로 시작합니다.
4. 대화창을 클릭하거나 Enter·Space를 눌러 읽습니다. 오른쪽 버튼으로도 진행할 수 있습니다.
5. 선택지는 마우스로 누르거나 방향키로 이동한 뒤 Enter로 고릅니다.
6. 첫 만남이 끝나면 다시 읽기로 다른 선택을 비교하세요. Esc는 시작 화면으로 돌아갑니다.

`run_game_261022.cmd`는 편집기 없이 현재 전체 게임을 실행하는 도우미입니다. 이 문서의 도형 시제품은 위의 F6으로 실행하세요. Godot가 필요 없는 배포용 exe는 후속 단계에서 만듭니다.

## 확인 입력을 나눈 이유

글자가 나오는 중에 누르면 문장 전체만 표시합니다. 다시 눌러야 다음 줄로 갑니다. 한 번의 입력으로 글자가 완성되는 동시에 대사까지 넘어가면 문장을 읽지 못할 수 있기 때문입니다.

선택을 고르는 입력은 답변을 한 번 확정하는 데만 사용합니다. 그 입력으로 첫 반응 대사가 사라지지 않게 했습니다. 키를 길게 누를 때의 반복 이벤트도 무시합니다.

## 두 선택의 차이

| 선택 | 반응 | 내부 호감도 |
|---|---|---:|
| 이 책을 고른 이유가 궁금해요. | 책 이야기를 더 나누고 서윤이 미소를 보임 | 1 |
| 오늘은 조용히 읽다가 갈게요. | 물을 더 가져다주고 조용히 읽을 시간을 내어줌 | 0 |

숫자는 게임 화면에 표시하지 않습니다. 두 선택 모두 존중하는 반응으로 구성했습니다. 22단계의 완료 화면은 전체 이야기의 엔딩이 아니라 첫 장면 실습의 끝입니다. 호감도 누적과 두 엔딩은 23단계에서 연결합니다.

## 대사를 바꿔보기

F8로 실행을 멈춘 뒤 `data/scene01_dialogue_261022.json`을 엽니다. `common`의 첫 대사에서 `text` 값만 짧게 바꾸고 저장한 뒤 시제품 장면을 F6으로 비교하세요. 인물과 장면을 연결하는 ID, 따옴표와 쉼표는 유지합니다.

`speaker`는 `narrator`가 이야기, `player`가 나, `seoyun`이 서윤입니다. `expression`은 `neutral`, `smile`, `thoughtful`, `shy`를 사용할 수 있습니다. 최종 캐릭터 그림이 아닌 임시 얼굴 표시가 바뀝니다.

선택지 문구와 점수는 `data/story_outline_261022.json`의 C01에서 읽습니다. 선택 후 대사는 실행 대본의 `reactions`에 있는 `C01_A`·`C01_B`에서 읽습니다. 같은 선택 ID로 두 데이터를 연결합니다.

## 글자 표시 속도 바꿔보기

왼쪽 씬 트리의 맨 위 **Scene01**을 선택하고 인스펙터의 **Characters Per Second**를 바꿔보세요.

- 32: 기본 속도
- 60: 더 빠르게 표시
- 0: 문장을 즉시 표시

즉시 표시해도 다음 대사로 자동 진행하지는 않습니다. 값을 바꾼 뒤 Ctrl + S → F6으로 실행하세요.

## 이번 구조

게임은 시작 화면, 대화, 선택, 첫 장면 완료의 네 상태를 가집니다. 현재 상태에서 허용한 입력만 처리합니다. 선택 화면에서는 대화창을 눌러도 선택이 확정되거나 다음 줄로 넘어가지 않습니다.

대본은 JSON에, 화면 배치는 씬에, 진행 규칙은 스크립트에 나눠두었습니다. 다음 단계에서 대사를 늘려도 모든 줄을 코드에 직접 적을 필요가 없습니다.

임시 배경과 인물은 코드로 그린 표시이며 최종 그림 목록의 제작 완료를 뜻하지 않습니다. 효과음과 음악, 저장 기능도 아직 적용하지 않았습니다.

## 완료 기준

- [ ] 첫 장면을 처음부터 끝까지 읽었다.
- [ ] 표시 중 확인 입력은 문장만 완성하는 것을 확인했다.
- [ ] 두 선택의 서로 다른 반응과 표정을 확인했다.
- [ ] 다시 읽기에서 이전 선택과 점수가 초기화된다.
- [ ] 선택 중 Esc로 나갔다가 다시 시작해도 대화가 진행된다.
- [ ] 대사 한 줄이나 글자 표시 속도를 직접 바꿨다.

자동 검사에서는 실제 키·마우스로 위 흐름과 반복 선택 방지, 반응 건너뛰기 방지를 확인했습니다. 다음 23단계는 공통 장면 2개와 선택 2개를 더해 두 엔딩까지 완주하는 것입니다.
