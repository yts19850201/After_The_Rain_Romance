# 31단계 · 호감도와 관계 변화 알아보기

현재 소스는 `0.2.0-dev31` 개발 버전입니다. 기존 v0.1.0 배포본과 저장 형식을 유지하면서 관계 표시를 추가했습니다. 이번에는 서윤 한 명과 기존 세 선택을 그대로 사용합니다.

## 실행과 확인

1. `run_game_261022.cmd`로 실행하거나 Godot에서 F5를 누릅니다. 시작 화면에 **31단계 실습**이 보이는지 확인하세요. 예전 Windows 배포 exe에는 이번 기능이 없습니다.
2. 새 이야기를 시작하면 왼쪽 위에 관계 이름, **호감도 0 / 3**, 진행 막대가 나타납니다.
3. 첫 선택에서 **이 책을 고른 이유가 궁금해요.**를 고르면 +1 안내와 **알아가는 사이**를 볼 수 있습니다.
4. 처음부터 다시 읽으며 다른 답변을 고르면 **호감도 유지**로 표시됩니다. 감소나 실패로 표시하지 않습니다.
5. 선택 직후 저장한 다음 다시 불러오세요. 관계 단계와 수치가 복구되며 +1 안내를 다시 재생하거나 점수를 다시 더하지 않습니다.

| 호감도 | 관계 표시 |
|---|---|
| 0 | 낯선 사이 |
| 1 | 알아가는 사이 |
| 2 | 편안한 사이 |
| 3 | 가까운 사이 |

이름과 막대는 게임의 현재 진행 값을 이해하기 위한 표시입니다. 엔딩 조건은 기존처럼 합계 2 이상이면 E01, 그보다 낮으면 E02입니다. 날짜·반복 행동·새 인물은 이번 단계에 추가하지 않았습니다.

## 표시와 진행 값 나누기

`data/story_outline_261022.json`의 `affection.levels`에서 관계 이름을 정합니다. `scripts/relationship_panel_261022.gd`는 점수를 받아 글자와 막대를 표시하며 선택 점수를 직접 변경하지 않습니다. 실제 점수는 기존처럼 선택 기록에서 계산합니다.

선택 후 약 4초 동안 증가 또는 유지 안내를 보여줍니다. 설정·저장 등 창이 열려 있으면 막대 움직임과 안내 시간을 잠깐 멈춥니다. 다음 선택 화면이나 장면, 메뉴로 이동하면 안내를 정리합니다. 엔딩 감상에서는 현재 플레이의 호감도를 숨기고, 감상이 끝나면 원래 관계 표시를 복구합니다.

관계 이름과 막대 값을 저장 파일에 따로 추가하지 않았으므로 기존 schema 1 저장도 읽을 수 있습니다. 숫자와 선택 기록을 복원한 뒤 관계 이름을 다시 계산합니다.

- [ ] `affection.levels`의 관계 이름 하나를 바꿔 표시를 비교했다. `min` 값과 점수는 그대로 둔다.
