# 35단계 · 엔딩 확장과 Windows 배포본

현재 버전은 **v0.2.0**입니다. 기존 첫 만남의 두 엔딩을 보존하고 새로운 한 주에 세 결말을 추가했습니다. 금요일에 **한 주 마치기**를 누르면 조건에 맞는 마지막 대화가 시작됩니다. 끝까지 읽으면 결과 화면과 엔딩 감상에 남습니다.

## 주간 엔딩 조건

| 우선순위 | 제목 | 조건 |
|---|---|---|
| 1 | 둘이 남겨 둔 다음 장 · W01 | 호감도 8 이상, **다음에 앉을 자리** 감상 완료 |
| 2 | 세 사람의 첫 모임 · W02 | 호감도 5 이상, **세 사람이 고른 첫 질문** 감상 완료 |
| 3 | 천천히, 다음 주에도 · W03 | 위 두 조건에 해당하지 않을 때 |

두 조건을 모두 채우면 W01이 나옵니다. 호감도만 높고 해당 추가 이야기를 읽지 않았다면 그 엔딩은 열리지 않습니다. W03도 관계를 이어가는 결말이며 게임 오버가 아닙니다. 본편 E01·E02와 합쳐 엔딩은 총 다섯 가지입니다.

## 직접 확인하기

1. `builds/Windows_v0.2.0_261022/AfterTheRain_261022.exe`를 실행하고 **새로운 한 주 시작**을 누르세요. Godot가 필요하지 않습니다.
2. [33단계 예시](lesson33_261022.md)대로 수요일까지 진행하고 네 추가 이야기를 읽으세요. 목요일 두 번 행동하면 호감도가 8이 됩니다. 금요일을 마치면 W01을 읽습니다.
3. W02는 월요일 책 읽기·정리, 화요일 책 읽기·정리, 수요일 안부 나누기 후 **세 사람이 고른 첫 질문**을 읽고 나머지 날을 마치면 볼 수 있습니다. **다음에 앉을 자리**를 읽지 않은 상태입니다.
4. W03은 매일 행동을 쉬고 넘어가도 볼 수 있습니다. 화요일 민재 소개는 읽고 진행하세요.
5. 엔딩 대화 도중 저장하고 게임을 껐다 켜서 같은 문장으로 이어지는지 확인하세요. 마지막 문장을 읽기 전에는 새 엔딩이 감상 목록에 해제되지 않습니다.
6. 완료 화면의 **엔딩 감상**에서 다시 읽거나 Esc로 나오세요. 호감도·행동·진행 슬롯을 바꾸지 않고 원래 화면으로 돌아옵니다. 목록은 아래로 스크롤할 수 있습니다.

## 저장 호환성

| 저장 형식 | 현재 버전에서의 처리 |
|---|---|
| 본편 schema 1 | 그대로 본편 장면·선택 반응·엔딩을 복구 |
| 34단계 주간 schema 2 / life_version 1 | 날짜·행동·읽은 이야기·대화 위치 유지 |
| 34단계 한 주 마무리 저장 | 조건에 맞는 새 엔딩 첫 줄부터 읽기 |
| 새 주간 schema 3 / life_version 2 | 엔딩 대화와 마무리까지 저장·복구 |

새 저장은 이전 프로그램에서 읽지 못합니다. 새 시작은 기존 슬롯을 지우지 않으며, 같은 슬롯에 수동 저장하면 덮어씁니다. 본편 엔딩 기록과 설정 파일은 유지합니다. 주간 엔딩은 `week_endings_261022.json`에 따로 기록해 예전 본편의 기록과 섞이지 않게 했습니다.

저장 기본 위치는 `%APPDATA%\Godot\app_userdata\After the Rain - Romance\romance`입니다. 자동 검사는 이 경로 대신 `.godot` 또는 새 임시 폴더만 사용합니다.

## 전달할 파일

- `builds/AfterTheRain_Windows_v0.2.0_261022.zip`: 다른 사람에게 전달할 전체 패키지.
- `builds/Windows_v0.2.0_261022/AfterTheRain_261022.exe`: 현재 PC에서 바로 실행할 파일.
- 같은 폴더의 pck, 실행 안내, 변경 기록, 라이선스를 함께 보관하세요. exe만 보내면 실행되지 않습니다.
- `builds/SHA256SUMS_v0.2.0_261022.txt`: ZIP 검사값.

기존 v0.1.0 폴더·ZIP과 공개 GitHub 릴리스는 그대로입니다. 이번 작업은 로컬 배포본 제작까지이며 푸시·업로드는 하지 않습니다.

## 확인한 범위

순수 모델에서 하루 선택 7가지의 5일 조합 **16,807개**를 검사했습니다. 각 날의 추가 이야기는 조건이 되는 즉시 읽는 방식이며, 순서가 다른 모든 클릭·읽기 전략을 전수 검사했다는 뜻은 아닙니다. 별도 실제 진행 검사에서 이야기를 읽지 않는 경로, 조건이 겹치는 경로, 세 엔딩 완료와 감상 복귀를 확인했습니다.

소스의 기존 8개 선택 분기와 일상 제한·저장을 검사했습니다. 새 ZIP은 프로젝트 밖에 풀어 내부 파일 해시, 실제 exe의 다섯 엔딩·3슬롯·라이선스, 종료 후 schema 1·2·3 복원, 실제 화면을 확인했습니다. [배포 검사 결과](../distribution/validation_results_v020_261022.json)와 [검사 기록](../distribution/qa_report_v020_261022.md)에 남겼습니다.

사람의 실제 읽기 시간과 외부 플레이어 피드백은 아직 미수집입니다. 다른 PC의 호환성과 체감 음량은 직접 플레이하며 확인해주세요. 여기까지가 계획한 31~35단계 관계 고도화 범위입니다.
