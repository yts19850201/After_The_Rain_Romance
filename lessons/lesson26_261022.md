# 26단계 · 실제 대본과 그림·음악 적용

목표는 도형 시제품을 읽을 수 있는 짧은 작품으로 바꾸는 것입니다. 최종 대본에 맞춰 배경 2장, 서윤 표정 4종, 음악 2곡과 효과음 3종을 적용했습니다. 한국어 글꼴도 프로젝트에 포함했습니다.

대본은 세 번의 만남, 선택별 반응과 마무리, 엔딩 두 개를 합쳐 171개 대사 단위입니다. 이는 모든 분기를 합한 수이며 한 번에 전부 읽는다는 뜻은 아닙니다. 실제 읽기 시간은 27단계에서 측정합니다.

그림은 image_gen으로 만들었습니다. 낮 카페와 기본 인물 그림을 먼저 만든 뒤 같은 이미지를 참고해 저녁과 표정을 만들었습니다. 음악과 효과음은 외부 샘플 없이 사인파와 배음을 합성해 제작했습니다. 각 음악은 약 20초 길이로 반복됩니다. 설정에서 음악과 효과음을 따로 조절할 수 있습니다.

출처와 이용 조건은 `assets/ASSET_SOURCES_261022.md`, 그림 생성 기록은 `assets/art/GENERATION_PROMPTS_261022.md`에 있습니다. Noto Sans KR의 OFL 전문도 글꼴 옆에 포함했습니다. 선택적 엔딩 CG는 보류하고 기본 저녁 배경을 사용합니다.

## 직접 확인할 것

- [ ] 서윤의 네 표정과 낮·저녁 배경을 확인한다.
- [ ] 가장 긴 대사와 선택지가 창 밖으로 나가지 않는지 본다.
- [ ] 음악과 효과음이 읽기를 방해하지 않는 음량인지 듣는다.
- [ ] 설정의 켜기·끄기와 음량 조절을 각각 시험한다.
- [ ] 두 엔딩의 대사와 선택 반응이 자연스럽게 이어지는지 읽는다.

다음은 **27단계 전체 플레이 점검**입니다. 두 엔딩까지 직접 읽은 시간, 어색한 문장, 너무 빠르거나 큰 소리를 기록해 주세요. 배포용 독립 실행 파일은 29단계에서 만듭니다.
