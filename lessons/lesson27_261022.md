# 27단계 · 전체 플레이 점검

전체 8개 선택 조합에서 두 엔딩이 각각 네 조합으로 나오는지 확인했습니다. 글자 표시와 다음 줄 입력 구분, 반복 선택 방지, 배경·표정, 모든 대사 길이, 엔딩 감상 복귀를 검사했습니다. 선택 전후 저장, 덮어쓰기, 손상 파일 안내, 종료 후 이어 읽기와 설정·엔딩 기록도 확인했습니다.

배포 준비에서 확인해 고친 내용은 대본 JSON을 배포 데이터에 명시적으로 포함한 것, 버전 표시, 배포본에서도 찾을 수 있는 출처 안내와 라이선스 전문 화면입니다. 기존 22단계 시제품은 별도로 보존합니다.

사용자는 아직 직접 플레이 전이라고 답했습니다. **사람의 실제 읽기 시간과 외부 피드백은 미수집**입니다. 자동으로 대사를 넘기는 검사 시간은 플레이 시간으로 쓰지 않습니다. 10~20분은 여전히 목표입니다.

## 첫 플레이에서 확인할 것

- [ ] 시작부터 엔딩까지 걸린 시간을 잰다. 잠깐 멈춘 시간은 따로 적는다.
- [ ] A→A→A와 B→B→B로 두 엔딩을 읽는다.
- [ ] 특히 C03의 답변과 마지막 이야기가 자연스럽게 이어지는지 본다.
- [ ] 음악과 효과음이 적당한지, 오래 읽어도 글자가 편한지 확인한다.
- [ ] `distribution/feedback_log_261022.csv` 또는 저장소 이슈에 결과를 남긴다.

사용자에게서 받지 않은 읽기 시간·만족도·판매 성과를 만들어 기록하지 않습니다. 외부 테스트 요청 메시지도 임의로 보내지 않습니다.
