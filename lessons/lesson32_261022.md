# 32단계 · 날짜와 하루 행동

`run_game_261022.cmd` 또는 Godot F5로 실행하고 **새로운 한 주 시작**을 누르세요. 현재 소스는 `0.2.0-dev34`입니다. 기존 Windows v0.1.0 실행 파일에는 이 기능이 없습니다.

기존 세 번의 만남은 **첫 만남 읽기 · 기존 이야기**에 남겨두었습니다. 새 일상은 그 뒤 다시 카페에 들르는 월요일부터 금요일까지 5일입니다. 본편 엔딩 화면의 **서윤과 새로운 한 주**로도 시작할 수 있습니다. 수요일은 카페 휴무이므로 초대받아 오전에 책 모임 준비를 돕는 설정입니다.

## 직접 해보기

1. 왼쪽 위 호감도와 오른쪽 위 날짜·남은 행동을 확인하세요.
2. **서윤과 안부 나누기**, **함께 책 읽기**, **카페 정리 돕기** 중 하나를 고르고 대화를 끝까지 읽으세요.
3. 행동 한 번에 호감도 +1, 남은 행동 -1이 반영됩니다. 같은 행동은 하루 한 번, 전체 행동은 하루 두 번까지 할 수 있습니다.
4. 두 번째 행동 후 **오늘 마치고 다음 날로**를 누르세요. 남은 행동이 있을 때 누르면 해당 횟수는 포기하고 넘어갑니다.
5. 금요일을 마치면 **함께 보낸 한 주**에서 결과와 기록을 확인합니다. 이번 단계의 마무리 화면이며 새 분기 엔딩은 35단계 범위입니다.

| 주간 호감도 | 관계 표시 |
|---|---|
| 0~2 | 다시 만난 사이 |
| 3~5 | 알아가는 사이 |
| 6~8 | 편안한 사이 |
| 9~10 | 가까운 사이 |

새 주간 호감도는 0에서 시작합니다. 본편의 0~3 점수를 가져오거나 본편 엔딩 조건을 바꾸지 않습니다. 모두 쉬고 넘어가도 한 주를 마칠 수 있습니다.

## 저장과 구현

일상 화면, 대화 도중, 한 주 마무리에서 기존 3슬롯을 사용합니다. 같은 슬롯에 저장하면 해당 슬롯을 덮어씁니다. 대화 중간 저장 후 불러오면 표시하던 글자 위치도 복구하고 행동·호감도를 다시 지급하지 않습니다.

`data/cafe_life_261022.json`은 날짜·행동·대본을 담습니다. `scripts/cafe_week_state_261022.gd`는 날짜와 행동 기록을 관리하고 호감도를 계산합니다. `scripts/cafe_life_261022.gd`는 이를 화면에 보여줍니다. 진행 규칙과 화면을 나누면 이후 행동을 바꿀 때 확인할 범위가 줄어듭니다.

- [ ] 같은 날 같은 행동을 두 번 고를 수 없는지 확인했다.
- [ ] 두 번 행동하면 다른 행동도 막히는지 확인했다.
- [ ] 대화 중간에 저장하고 불러와 횟수·호감도가 그대로인지 확인했다.
- [ ] 쉬는 날을 포함해 금요일까지 진행했다.

자동 검사에서는 위 제한, 하루 이동, 모든 날을 쉬는 진행, 저장 복원과 새 프로세스의 이어 읽기를 확인했습니다. 다음은 [33단계 추가 이야기](lesson33_261022.md)입니다.
