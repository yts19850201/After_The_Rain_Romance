## 최신 업데이트 · 2026-10-22 · v0.2.0

35단계까지의 관계·일상 확장을 기존 **After_The_Rain_Romance** 저장소에 반영했습니다. 아래의 최초 v0.1.0 소개와 배포 안내는 그대로 보존했습니다.

- **관계 표시:** 서윤과의 호감도·관계 단계, 행동 후 변화 안내를 추가했습니다.
- **새로운 한 주:** 월~금 5일 동안 하루 두 번 행동합니다. 안부 나누기·책 읽기·정리 돕기를 고르고 한 주 기록을 확인할 수 있습니다.
- **이야기와 인물:** 조건에 따라 열리는 이야기 4편과 30세 서브 캐릭터 민재를 추가했습니다.
- **엔딩 확장:** 주간 엔딩 3종을 더해 기존 본편과 합쳐 총 5종입니다. 끝까지 읽은 엔딩은 감상 목록에서 다시 볼 수 있습니다.
- **저장 호환성:** 기존 본편·34단계 일상 저장을 읽으며 새 주간 진행과 엔딩 대화 중간도 저장·복구합니다.

현재 공개하는 것은 **v0.2.0 소스와 커밋 이력**입니다. Windows 실행용 ZIP과 검사값은 제작 PC에 보관하며 공개 업로드하지 않습니다. 아래 기존 Windows 다운로드 링크는 **v0.1.0**입니다.

소스에서 `project.godot`를 Godot로 열고 F5 → **새로운 한 주 시작**을 선택하세요. 기존 본편은 **첫 만남 읽기 · 기존 이야기**로 실행합니다. [35단계 실행·엔딩 안내](lessons/lesson35_261022.md)와 [검사 기록](distribution/qa_report_v020_261022.md)에 상세 내용을 정리했습니다.

본편 분기, 주간 엔딩·저장·재실행과 화면 검사를 통과했습니다. 사람의 실제 읽기 시간과 외부 피드백은 아직 미수집입니다.
