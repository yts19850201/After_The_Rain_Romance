# 비가 그치면, 한 잔 더

비를 피해 들어간 작은 카페. 책 한 권에서 시작한 대화가 다음 만남의 이유가 됩니다.

마감에 쫓기는 일러스트레이터인 당신은 카페 주인 서윤과 세 번의 오후를 보냅니다. 어떤 책을 좋아하는지, 쉬는 날에는 무엇을 하는지. 서두르지 않고 건넨 답변이 두 사람의 다음 이야기를 바꿉니다.

- 카페 한 곳에서 이어지는 세 번의 만남
- 답변 세 번에 따라 달라지는 두 엔딩
- 저장 슬롯 3개와 읽은 엔딩 다시 보기
- 비 오는 낮과 비가 그친 저녁의 배경, 서윤의 네 표정
- 한국어 대사, 글자 표시 속도와 음악·효과음 설정

**Windows x86_64 무료 시험 배포본 v0.1.0**입니다. ZIP을 모두 풀고 실행 파일을 열면 됩니다. Godot 설치와 인터넷 연결은 필요하지 않습니다.
