# v0.1.0 · 무료 시험 배포

세 번의 카페 방문과 세 선택, 두 엔딩을 담은 첫 Windows 배포본입니다. 최종 읽기 시간과 외부 사용자 피드백은 미수집 상태이므로 시험 배포로 표시합니다.

- 두 엔딩과 잠금 해제 후 감상
- 저장 슬롯 3개, 선택 전후 이어 읽기
- 글자 속도, 음악·효과음, 장면 전환 설정
- 낮·저녁 배경 2종, 서윤 표정 4종, 음악 2곡과 효과음 3종
- 한국어 글꼴 포함, Godot 설치 없는 Windows x86_64 실행

그림과 대본 등은 AI 도움으로 제작했습니다. 실행 중 AI 서비스나 인터넷 연결을 사용하지 않습니다. 이 버전에는 노출·성적 장면이나 유료 결제 기능이 없습니다.

Windows 단일 개발 PC에서 검증했으며 다른 그래픽 카드와 PC의 호환성은 추가 확인이 필요합니다. 코드 서명은 적용하지 않았습니다. Steam·itch.io 심사나 유료 판매 등록을 마쳤다는 뜻은 아닙니다.

첫 플레이 뒤 읽기 시간과 어색한 대사, 실행·저장 문제를 피드백으로 모아 v0.1.1 수정 범위를 정합니다.
