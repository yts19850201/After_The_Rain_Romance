## 배포 준비에서 반영한 것

- 대본 JSON을 export include_filter에 지정해 배포에서 빠지지 않게 했습니다.
- 실행 파일·pck·실행 안내·버전 기록·엔진 MIT와 구성 요소 고지·폰트 OFL·자산 출처를 묶었습니다.
- 게임의 버전을 표시하고 제작 정보에 AI 도움과 배포본의 출처 위치를 적었습니다.
- 게임 안에서 엔진·폰트 라이선스 전문을 볼 수 있게 했습니다.
- 재현 가능한 빌드·ZIP 검증 스크립트와 별도 QA 저장 경로를 준비했습니다.
- 플랫폼 공식 문서 검토, 배포 소개글, 실제 화면 4장과 공개 이슈 양식을 작성했습니다.

## 아직 확인하지 않은 것

- 사람의 실제 읽기 시간, 대사의 자연스러움과 음악·효과음의 체감 음량
- 외부 플레이어의 평가와 다른 PC·그래픽 드라이버 호환성
- Steam·itch.io 등록·심사, 연령등급 승인, 유료 판매·다운로드·매출 성과

첫 피드백은 `feedback_log_261022.csv` 또는 GitHub 이슈로 받습니다. 현재 표는 헤더만 있으며 실제 피드백을 만들어 넣지 않았습니다. v0.1.1은 실행·저장 문제부터 수정하고, 읽기 시간과 문장·음량 의견을 그다음으로 반영합니다.
