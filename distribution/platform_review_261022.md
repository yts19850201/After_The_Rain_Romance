# 첫 배포 방식과 플랫폼 검토

확인일: 2026-10-22. 현재 실제 빌드는 노출·성적 장면이 없는 성인 인물의 연애 대화 게임입니다. 장기 목표인 어덜트 게임의 판매 가능성과 이 빌드를 구분합니다.

## 이번 배포에서 정한 것

**GitHub 공개 저장소와 무료 Windows 시험 배포본(v0.1.0)**을 사용합니다. 아직 직접 플레이나 외부 피드백이 없으므로 유료 판매·수익 목표를 걸지 않습니다. GitHub 공개 저장소는 사용자가 선택했습니다. Steam·itch.io에는 계정을 만들거나 결제·심사 제출·게임 업로드를 하지 않았습니다.

| 항목 | Steam | itch.io | 이번 GitHub 배포 |
|---|---|---|---|
| 시작 비용 | 제품당 Steam Direct 100 USD | 페이지·파일 등록은 무료 | 무료 소스 보관과 시험 배포 |
| 판매 비용 | 실제 배포 계약에서 수익 배분·세금 조건 확인 필요 | 수익 배분 0~100% 설정, 기본 예시 10%; 결제 처리 비용 별도 | 결제 기능·판매 수수료 없음 |
| 공개 준비 | 신원·은행·세금 정보, 스토어와 빌드 검토, 초기 출시 대기 조건 | 소개·다운로드·플랫폼과 콘텐츠 표시, 유료라면 결제·정산 설정 | README, 실행 ZIP, 해시, 라이선스, 피드백 안내 |

Steam 공식 안내는 초기 출시에서 앱 비용 납부 후 30일 대기와 Coming Soon 최소 2주 공개를 설명합니다. 등록비는 조정 총매출 1,000 USD 이후 정산에서 회수될 수 있다고 안내합니다. 무료 게임도 제품 등록과 검토 절차를 따릅니다. [Steam Direct 공식 안내](https://partner.steamgames.com/steamdirect/?l=english).

itch.io의 플랫폼 수익 배분과 결제 처리 비용은 별개입니다. 공식 문서의 10 USD 판매 예시는 플랫폼 10%와 결제 비용 0.30 USD+2.9%를 뺀 8.41 USD이며, 지역·계정·환전·정산 조건에 따라 실제 금액은 달라집니다. 이번 빌드는 0원 시험 배포이므로 이 예시를 예상 수익으로 쓰지 않습니다. [itch.io 결제 안내](https://itch.io/docs/creators/payments), [등록 비용과 최소 가격](https://itch.io/docs/creators/faq).

## 현재 콘텐츠와 AI 표시

- 화면에 등장하는 서윤은 28세, 주인공은 29세입니다. 이 버전에는 노출·성적 장면, 도박·결제, 실시간 생성 대사나 그림이 없습니다.
- 배경 2장과 표정 4종은 image_gen으로 생성했습니다. 대본·코드·합성 음원 제작에도 AI 도움을 사용했습니다. 그림만 AI 사용으로 적고 대본을 누락하지 않습니다.
- Steam 콘텐츠 설문은 플레이어에게 제공되는 사전 생성 AI 콘텐츠와 실행 중 생성 콘텐츠를 구분합니다. 현재 빌드는 사전 생성 콘텐츠에 관한 설명을 준비하며 실행 중 AI 생성은 사용하지 않습니다. [Steam 콘텐츠 설문](https://partner.steamgames.com/doc/gettingstarted/contentsurvey?language=english).
- 이 문서는 연령등급·플랫폼 심사 승인을 받은 사실을 뜻하지 않습니다. 실제 등록 시 제출하는 빌드 전체와 배포 지역에 맞춰 설문·등급 조건을 확인합니다.

## 이후 어덜트 작품에서 다시 확인할 것

Steam은 성인 콘텐츠의 정확한 표시와 연령 제한을 요구하며, 현재 안내에서는 실행 중 AI로 생성하는 Adult Only Sexual Content를 허용하지 않는다고 설명합니다. 이는 사전에 생성한 그림의 일괄 금지라는 뜻은 아닙니다. 별도 작품의 실제 콘텐츠와 권리·설문을 기준으로 다시 검토합니다. [Steam Direct](https://partner.steamgames.com/steamdirect/?l=english), [AI 콘텐츠 설문](https://partner.steamgames.com/doc/gettingstarted/contentsurvey?language=english).

itch.io는 성인 콘텐츠 표시를 요구하며, 플랫폼에서 허용되는 콘텐츠와 결제 업체가 판매를 허용하는 콘텐츠가 같다고 보장하지 않습니다. 실존 인물을 성적으로 표현한 이미지, 미성년자 성적 표현, 비동의·강요 등의 금지 조건을 공식 문서에서 다시 확인해야 합니다. 이번 비성적 연애 게임을 근거로 다음 어덜트 작품도 판매할 수 있다고 단정하지 않습니다. [품질·성인 표시 안내](https://itch.io/docs/creators/quality-guidelines), [성인 콘텐츠·판매 제한 FAQ](https://itch.io/docs/creators/faq).
