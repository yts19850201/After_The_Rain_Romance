# v0.2.0 · 관계와 일상 확장

기존 세 번의 만남을 보존하고 월~금 다섯 날의 새 일상을 추가했습니다. 하루 두 행동과 읽은 이야기에 따라 세 주간 엔딩 중 하나로 이어집니다.

- 호감도·관계 표시, 하루 행동 제한과 한 주 기록.
- 서윤 이야기 3편, 30세 민재의 소개와 책 모임 준비 이야기 1편.
- 주간 엔딩: 둘이 남겨 둔 다음 장 / 세 사람의 첫 모임 / 천천히, 다음 주에도.
- 기존 본편 2종을 포함한 총 5종 엔딩 감상. 끝까지 읽은 엔딩만 해제합니다.
- 기존 본편 schema 1과 주간 schema 2 불러오기. 새 주간 저장은 schema 3이며 엔딩 대화 중간도 복구합니다.
- 새 인물 그림 1종과 일상·엔딩 대사 84개 단위 추가. 새 주간 호감도는 본편과 별도로 0에서 시작합니다.
- 실행 파일·pck·안내·출처·라이선스를 담은 Windows x86_64 ZIP.

그림과 대본 등은 AI 도움으로 제작했습니다. 실행 중 인터넷이나 AI 서비스를 사용하지 않습니다. 노출·성적 장면이나 결제 기능은 없습니다.

Godot 설치 없이 실행합니다. ZIP 전체를 풀고 exe와 pck를 같은 폴더에 두세요. 기존 v0.1.0 ZIP은 보존하며 이번 패키지는 별도 경로로 만듭니다.

이 문서는 로컬 시험 배포본의 변경 기록입니다. GitHub 푸시·릴리스 업로드, Steam·itch.io 등록과 유료 판매는 이번 작업에 포함하지 않습니다. 사람의 읽기 시간·외부 피드백은 아직 미수집입니다.
