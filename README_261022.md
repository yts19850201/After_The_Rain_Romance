# 비가 그치면, 한 잔 더

작은 카페에서 세 번의 만남을 거치며 다음 약속을 만드는 2D 연애 비주얼 노벨입니다. 주인공은 29세, 카페 주인 서윤은 28세입니다.

현재 버전은 **35단계까지 완료한 v0.2.0**입니다. **새로운 한 주 시작**에서 월~금 5일, 하루 두 행동, 조건부 이야기 4편과 민재를 만나고 세 주간 엔딩 중 하나로 이어집니다. [35단계 안내](lessons/lesson35_261022.md)에 엔딩 조건과 새 실행 파일 사용법을 정리했습니다. 공개된 v0.1.0 Windows 배포본에는 이번 확장이 없습니다.

기존 세 장면·세 선택·두 엔딩은 **첫 만남 읽기 · 기존 이야기**에 보존했습니다. 본편 엔딩 화면에서도 새로운 한 주를 시작할 수 있습니다. 그림·음악, 엔딩 감상과 3슬롯 저장을 유지합니다. 사람의 실제 읽기 시간과 외부 피드백은 아직 미수집입니다.

## Godot 없이 실행하기

현재 PC에서는 `builds/Windows_v0.2.0_261022/AfterTheRain_261022.exe`를 더블클릭하세요. 다른 사람에게는 `builds/AfterTheRain_Windows_v0.2.0_261022.zip`을 전달합니다. 모두 압축 해제하고 exe를 실행하며, 같은 폴더의 pck·안내·라이선스를 함께 보관해야 합니다. 검사값은 `builds/SHA256SUMS_v0.2.0_261022.txt`에 있습니다.

기존 [GitHub Releases의 v0.1.0](https://github.com/yts19850201/After_The_Rain_Romance/releases/tag/v0.1.0)과 로컬 ZIP은 유지했습니다. 현재 소스는 사용자가 다시 지정한 [After_The_Rain_Romance](https://github.com/yts19850201/After_The_Rain_Romance)에 보관합니다. 사용자가 소스만 보관하기로 정했으므로 새 Windows ZIP과 검사값은 로컬에만 둡니다. 저장소를 복제하면 소스만 내려받으며 `builds`는 포함되지 않습니다.

## 소스를 편집하고 실행하기

1. `run_game_261022.cmd`를 더블클릭합니다. 편집하려면 `open_editor_261022.cmd`로 열고 F5를 누르세요.
2. **새로운 한 주 시작**에서 행동을 고르거나 **첫 만남 읽기 · 기존 이야기**로 본편을 읽습니다. 클릭·Enter·Space로 읽으며 글자가 나오는 중에는 문장만 완성하고, 다음 입력에 다음 줄로 넘어갑니다.
3. 버튼은 클릭하거나 방향키와 Enter로 고릅니다. 새 일상은 같은 행동 하루 한 번, 총 두 번까지입니다. **추가 이야기**의 조건을 확인하고 **한 주 기록**에서 진행을 살펴보세요.
4. 위쪽 **저장 / 불러오기 / 설정 / 메뉴**를 이용하세요. Esc는 진행을 유지한 채 잠깐 멈추는 메뉴를 엽니다. 열린 창에서 Esc를 누르면 닫습니다.
5. 끝까지 읽은 엔딩은 시작 화면과 완료 화면의 **엔딩 감상**에서 다시 볼 수 있습니다. 감상 중 Esc는 원래 화면으로 돌아갑니다.

소스 실행 도우미는 옆 폴더 `Game_Edu_step1`의 Godot 실행 파일만 재사용합니다. 그 프로젝트는 수정하지 않습니다. 다른 PC에서는 Godot 4.7.2 Standard로 이 폴더의 `project.godot`를 가져오거나, `GODOT_ROMANCE_EXE` 환경 변수에 Godot 경로를 지정하세요. 소스 실행 도우미에는 Godot가 필요하며, 위 Windows 배포본은 Godot 설치 없이 실행합니다.

## 저장과 설정

- 수동 저장은 3슬롯입니다. 같은 슬롯에 다시 저장하면 덮어씁니다.
- 본편의 장면·선택 기록과 일상의 날짜·남은 행동·이야기 완료 기록을 각각 복구합니다. 두 모드 모두 대사 위치와 표시 중인 글자 수, 호감도와 화면을 복구합니다.
- 새로운 한 주는 주간 호감도 0~10을 독립적으로 시작합니다. 본편의 0~3 점수를 가져오지 않습니다. 새 시작은 슬롯과 확인한 엔딩 기록을 지우지 않습니다.
- 본편 schema 1과 34단계 일상 schema 2 저장을 읽습니다. 이전 주간 마무리는 새 엔딩 첫 줄로 이어집니다. 새 주간 저장은 schema 3이며 이전 버전 프로그램에서 읽을 수 없으므로 현재 버전으로 이어가세요.
- 주간 엔딩은 마지막 줄을 넘기면 해제됩니다. 본편 2종과 주간 3종을 엔딩 감상에서 다시 읽을 수 있으며, 감상 중 저장은 차단하고 원래 완료 화면이나 메뉴로 돌아옵니다.
- 엔딩 감상은 진행 슬롯을 덮어쓰지 않습니다. 끝나거나 Esc로 나오면 시작 화면 또는 원래 완료 화면으로 돌아갑니다.
- 글자 표시 속도, 음악·효과음의 켜기와 음량, 장면 전환 효과를 설정할 수 있습니다. 글자 속도 0은 즉시 표시입니다.
- 설정과 엔딩 기록은 진행 파일과 별도로 저장합니다. 파일이 손상됐거나 버전이 맞지 않으면 현재 진행을 유지하고 안내합니다.

Windows 기본 저장 폴더는 `%APPDATA%\Godot\app_userdata\After the Rain - Romance\romance`입니다. `save_1_261022.json`~`save_3_261022.json`, `settings_261022.json`, `profile_261022.json`, `week_endings_261022.json`을 사용합니다. 저장 파일에 개인 연락처는 넣지 않습니다.

## 검사와 직접 확인

35단계까지 5일 진행·행동 제한·추가 이야기 네 편·민재·세 주간 엔딩을 끝까지 검사했습니다. 하루 선택 7가지의 5일 조합 16,807개에서는 조건이 되면 이야기를 읽는 방식으로 세 엔딩의 판정과 우선순위를 확인했습니다. 대화 중 저장·새 프로세스 복구에서 점수·행동 중복이 없고 schema 1·2·3이 올바르게 복구되는지도 확인했습니다. 1280×720과 960×540에서 화면과 새 대사 84개 단위의 잘림을 검사했습니다. 자세한 범위는 [35단계 안내](lessons/lesson35_261022.md)에 있습니다. 계획한 고도화 구현은 완료했으며 이제 직접 플레이할 수 있습니다.

8개 선택 조합을 끝까지 진행해 E01과 E02가 각각 네 조합에서 나오는지 확인했습니다. 문장 표시와 다음 줄 입력 구분, 반복 선택 방지, 선택 전후와 엔딩에서의 저장, 손상 파일 대응, 새 프로세스에서 이어하기, 엔딩 감상 후 복귀를 검사했습니다. 실제 화면에서는 1280×720의 메뉴·대화·선택·설정·갤러리·저장 화면을 확인했습니다. 960×540에서는 메뉴와 대화·선택 배치, 모든 대사의 잘림 여부를 점검했습니다.

새 v0.2.0 ZIP을 별도 임시 폴더에 풀어 파일 해시, 실제 exe의 본편·주간 엔딩과 저장·감상, 종료 후 새 프로세스의 이어 읽기, 실제 화면을 검사했습니다. [v0.2.0 배포 검증 결과](distribution/validation_results_v020_261022.json), [점검 보고서](distribution/qa_report_v020_261022.md)에 범위와 한계를 기록했습니다. 기존 v0.1.0의 [검사 기록](distribution/qa_report_261022.md)도 보존했습니다.

기존 본편은 모든 분기를 합쳐 171개 대사 단위이며 새 일상·엔딩은 84개 단위를 더했습니다. **사람의 실제 읽기 시간과 외부 피드백은 아직 수집하지 않았습니다.** 10~20분은 본편의 측정값이 아닌 목표입니다. 첫 플레이 후 [피드백 양식](https://github.com/yts19850201/After_The_Rain_Romance/issues/new/choose)이나 `distribution/feedback_log_261022.csv`에 결과를 모아 다음 수정 범위를 정합니다. 자동 검사를 사람의 플레이 완료나 출시 성과로 대신 기록하지 않습니다.

이 폴더는 독립된 Git 저장소입니다. 현재 원격 저장소는 `yts19850201/After_The_Rain_Romance`입니다. 추가로 만들었던 v020 저장소는 사용자 요청에 따라 정리합니다. 새 빌드 파일은 로컬에만 보관하고, 이후 푸시나 바이너리 공개는 사용자가 요청할 때 진행합니다.
