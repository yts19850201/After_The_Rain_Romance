# 첫 오리지널 2D 연애 게임

**가제: 비가 그치면, 한 잔 더**

비를 피해 들어간 작은 카페에서, 세 번의 만남과 대화를 통해 서로의 다음 약속을 만드는 짧은 연애 게임입니다.

현재는 **21단계 기획 완료** 상태입니다. Godot 실행 프로젝트와 대화창은 22단계에서 만듭니다. 이번 폴더에는 기획 문서와 이야기·자산 목록의 초안만 있습니다.

## 이번 작품의 크기

| 항목 | 기획 기준 |
|---|---|
| 형식 | 대화·선택지 중심의 2D 비주얼 노벨 |
| 플레이 시간 | 한 번에 약 10~20분을 목표로 작성 |
| 주요 인물 | 플레이어 주인공 1명, 화면에 등장하는 상대 1명 |
| 장소 | 카페 한 곳, 비 오는 낮과 비가 그친 저녁의 배경 2종 |
| 이야기 | 공통 장면 3개, 선택지 3개, 엔딩 2개 |
| 진행 변수 | 호감도 1개, 0~3 |
| 첫 시제품 | 대화 읽기 → 선택 → 엔딩까지 한 번에 진행 |

장기 목표는 성인 대상 연애 게임을 완성하고 배포하는 것입니다. 첫 시제품은 성인 인물들의 대화·신뢰·데이트 약속까지 다룹니다. 제목, 이름, 분위기는 초안이며 기능과 이야기 규모를 먼저 고정합니다.
