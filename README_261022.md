# 첫 오리지널 2D 연애 게임

**가제: 비가 그치면, 한 잔 더**

비를 피해 들어간 작은 카페에서, 세 번의 만남과 대화를 통해 서로의 다음 약속을 만드는 짧은 연애 게임입니다.

현재는 **22단계 첫 대화창·선택지 구현 완료** 상태입니다. Godot 프로젝트에서 첫 장면 S01을 읽고 두 답변 중 하나를 고르면 다른 반응이 나타납니다. 다음 장면과 실제 엔딩 2개는 23단계에서 연결합니다.

## 실행

1. `open_editor_261022.cmd`를 더블클릭해 이 프로젝트를 Godot에서 엽니다.
2. F5를 누르고 **첫 만남 시작**을 선택하세요.
3. 클릭·Enter·Space로 대화를 읽습니다. 글자가 나오는 중에 누르면 현재 문장만 완성되고, 다음 입력에 다음 대사로 넘어갑니다.
4. 답변을 고르면 반응과 표정이 바뀝니다. 첫 만남이 끝나면 다시 읽거나 시작 화면으로 돌아갈 수 있습니다.
5. Esc는 현재 진행을 초기화하고 시작 화면으로 돌아갑니다.

편집기를 열지 않고 실행하려면 `run_game_261022.cmd`를 사용하세요. 두 실행 도우미는 기존 슈팅 폴더의 Godot 엔진만 재사용합니다. 이 시제품 실행에는 Godot가 필요하며 Windows 배포본은 아직 만들지 않았습니다.

다른 PC에서는 Godot 4 Standard에서 이 폴더의 `project.godot`를 가져와 실행할 수 있습니다. 실행 도우미를 쓰려면 `GODOT_ROMANCE_EXE` 환경 변수에 Godot 실행 파일 경로를 지정합니다. 프로젝트 데이터와 저장 위치는 슈팅 게임과 분리되어 있습니다.

## 폴더 관리

작업 위치는 `D:\양태식_작업이미지\Game_Edu_2D_Romance`입니다. 슈팅 게임의 `Game_Edu_step1`과 나란히 있는 별도 프로젝트로 관리합니다. 기존 슈팅 게임의 소스·배포본은 수정하지 않습니다.

이 폴더는 독립된 로컬 Git 저장소로 관리하며, 원격 저장소는 아직 연결하지 않습니다. GitHub 푸시는 별도 요청이 있을 때 진행합니다.

## 이번 작품의 크기

| 항목 | 기획 기준 |
|---|---|
| 형식 | 대화·선택지 중심의 2D 비주얼 노벨 |
| 플레이 시간 | 한 번에 약 10~20분을 목표로 작성 |
| 주요 인물 | 플레이어 주인공 1명, 화면에 등장하는 상대 1명 |
| 장소 | 카페 한 곳, 비 오는 낮과 비가 그친 저녁의 배경 2종 |
| 이야기 | 공통 장면 3개, 선택지 3개, 엔딩 2개 |
| 진행 변수 | 호감도 1개, 0~3 |
| 첫 시제품 | 대화 읽기 → 선택 → 엔딩까지 한 번에 진행 |

장기 목표는 성인 대상 연애 게임을 완성하고 배포하는 것입니다. 첫 시제품은 성인 인물들의 대화·신뢰·데이트 약속까지 다룹니다. 제목, 이름, 분위기는 초안이며 기능과 이야기 규모를 먼저 고정합니다.

## 구현 파일

- `project.godot`: 독립된 Godot 프로젝트 설정
- `scenes/scene01_261022.tscn`: 시작 화면, 대화창, 선택 버튼과 첫 장면 완료 화면
- `scripts/scene01_261022.gd`: 대사 표시와 입력, 선택 상태와 점수 처리
- `data/scene01_dialogue_261022.json`: 첫 장면의 임시 대사와 두 반응
- `scripts/cafe_placeholder_261022.gd`, `scripts/portrait_placeholder_261022.gd`: 코드로 그린 임시 카페와 인물
- `tests/dialogue_flow_261022.gd`: 실제 입력으로 두 선택과 재시작을 검사

카페와 인물은 기능을 확인하기 위한 임시 표시입니다. 최종 그림·음악 제작 상태와 구분하며, 26단계에서 최종 자산을 적용합니다.

## 확인 결과

키보드·마우스, 문장 완성과 다음 대사 구분, 두 선택과 반응, 점수 중복 방지, 다시 읽기·메뉴·Esc, 즉시 표시 모드를 검사했습니다. 실제 OpenGL 화면에서 메뉴·대화·선택·완료 화면도 확인했습니다. 진행 저장·불러오기와 효과음은 후속 단계에서 추가합니다.
