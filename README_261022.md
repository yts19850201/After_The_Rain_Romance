# 비가 그치면, 한 잔 더

작은 카페에서 세 번의 만남을 거치며 다음 약속을 만드는 2D 연애 비주얼 노벨입니다. 주인공은 29세, 카페 주인 서윤은 28세입니다.

현재 **26단계까지 구현**했습니다. 세 장면과 선택 세 번, 엔딩 두 개를 처음부터 끝까지 읽을 수 있습니다. 배경 2장과 표정 4종, 음악 2곡과 효과음 3종을 적용했고, 엔딩 감상과 저장 슬롯 3개를 추가했습니다. 그림의 별도 ZIP은 만들지 않고 프로젝트에 보관합니다.

## 실행하기

1. `run_game_261022.cmd`를 더블클릭합니다. 편집하려면 `open_editor_261022.cmd`로 열고 F5를 누르세요.
2. **새 이야기**를 누르고 클릭·Enter·Space로 읽습니다. 글자가 나오는 중에는 문장만 완성하고, 다음 입력에 다음 줄로 넘어갑니다.
3. 선택지는 클릭하거나 방향키와 Enter로 고릅니다. 답변에 따라 반응과 마지막 이야기가 달라집니다.
4. 위쪽 **저장 / 불러오기 / 설정 / 메뉴**를 이용하세요. Esc는 진행을 유지한 채 잠깐 멈추는 메뉴를 엽니다. 열린 창에서 Esc를 누르면 닫습니다.
5. 끝까지 읽은 엔딩은 시작 화면과 완료 화면의 **엔딩 감상**에서 다시 볼 수 있습니다. 감상 중 Esc는 원래 화면으로 돌아갑니다.

실행 도우미는 옆 폴더 `Game_Edu_step1`의 Godot 실행 파일만 재사용합니다. 그 프로젝트는 수정하지 않습니다. 다른 PC에서는 Godot 4 Standard로 이 폴더의 `project.godot`를 가져오거나, `GODOT_ROMANCE_EXE` 환경 변수에 Godot 경로를 지정하세요. **현재 실행에는 Godot가 필요합니다.** 독립 Windows 배포본은 29단계에서 만듭니다.

## 저장과 설정

- 수동 저장은 3슬롯입니다. 같은 슬롯에 다시 저장하면 덮어씁니다.
- 장면·대사 위치·표시 중인 글자 수·선택 기록·호감도·표정·배경을 복구합니다. 선택 화면과 선택 직후에도 저장할 수 있습니다.
- 새 이야기는 진행 점수를 초기화합니다. 슬롯과 확인한 엔딩 기록은 지우지 않습니다.
- 엔딩 감상은 진행 슬롯을 덮어쓰지 않습니다. 끝나거나 Esc로 나오면 시작 화면 또는 원래 완료 화면으로 돌아갑니다.
- 글자 표시 속도, 음악·효과음의 켜기와 음량, 장면 전환 효과를 설정할 수 있습니다. 글자 속도 0은 즉시 표시입니다.
- 설정과 엔딩 기록은 진행 파일과 별도로 저장합니다. 파일이 손상됐거나 버전이 맞지 않으면 현재 진행을 유지하고 안내합니다.

Windows 기본 저장 폴더는 `%APPDATA%\Godot\app_userdata\After the Rain - Romance\romance`입니다. `save_1_261022.json`~`save_3_261022.json`, `settings_261022.json`, `profile_261022.json`을 사용합니다. 저장 파일에 개인 연락처는 넣지 않습니다.

## 확인한 범위와 다음 단계

8개 선택 조합을 끝까지 진행해 E01과 E02가 각각 네 조합에서 나오는지 확인했습니다. 문장 표시와 다음 줄 입력 구분, 반복 선택 방지, 선택 전후와 엔딩에서의 저장, 손상 파일 대응, 새 프로세스에서 이어하기, 엔딩 감상 후 복귀를 검사했습니다. 실제 화면에서는 1280×720의 메뉴·대화·선택·설정·갤러리·저장 화면을 확인했습니다. 960×540에서는 메뉴와 대화·선택 배치, 모든 대사의 잘림 여부를 점검했습니다.

대본은 선택별 반응과 두 엔딩을 모두 합쳐 171개 대사 단위입니다. 실제 한 번의 읽기 시간은 아직 재지 않았습니다. 다음 **27단계**에서 두 엔딩을 직접 읽고, 10~20분 목표에 맞는지와 대화의 자연스러움·음량을 확인합니다. 28단계는 배포 준비, 29단계는 출시용 빌드, 30단계는 피드백 정리입니다.

이 폴더는 독립된 로컬 Git 저장소입니다. 원격 주소는 연결하지 않았으며, 푸시는 사용자가 요청할 때만 진행합니다.
